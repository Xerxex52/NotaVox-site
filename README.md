# NotaVox — site

Site public de l's app iOS NotaVox : page de support et politique de confidentialité,
utilisées comme URL de support et URL de confidentialité dans App Store Connect.

- `index.html` — présentation, support et FAQ (FR / EN)
- `privacy.html` — politique de confidentialité (FR / EN)
- `assets/` — feuille de style, sélecteur de langue, icône et captures

Publié via GitHub Pages depuis la branche `main`.
