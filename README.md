# NotaVox — site

Site public de l'app iOS NotaVox : page de support et politique de confidentialité,
utilisées comme URL de support et URL de confidentialité dans App Store Connect.

- `index.html` — présentation, prix, support et FAQ (FR / EN / DE / ES)
- `privacy.html` — politique de confidentialité (FR / EN / DE / ES)
- `assets/` — feuille de style, sélecteur de langue, icône, image de partage (`og.png`) et captures

Publié via GitHub Pages depuis la branche `main`.
